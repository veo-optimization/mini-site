Як створити username в Telegram

Для особистого акаунту (менеджер):

  1. Відкрийте Telegram
  2. Натисніть Меню (☰) або перейдіть у Налаштування
  3. Оберіть Редагувати профіль
  4. Натисніть на поле Username
  5. Введіть ім'я латиницею (букви, цифри, підкреслення). Наприклад: my_shop
  6. Username має бути 5–32 символи. У форму вводьте з символом @: @my_shop

Для каналу:

  1. Створіть канал: Меню → Новий канал
  2. Заповніть назву та опис, натисніть Готово
  3. У налаштуваннях каналу оберіть Тип каналу → Публічний канал
  4. Вкажіть username каналу (латиницею, 5–32 символи)
  5. У форму вводьте з @: @channel_name

Важливо: Username пишеться латиницею, без пробілів. У полі форми завжди додавайте @ на початку.
